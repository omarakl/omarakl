**Technologies**: RAG, GPT-4o-mini, ChromaDB, FastAPI, Streamlit

Production-grade Retrieval-Augmented Generation (RAG) system for querying technical PDFs with accurate citations.

**Key Features**:
- Document ingestion, chunking, and embedding pipeline
- Similarity-based retrieval with ChromaDB
- Local LLM integration using Ollama (no API costs)
- Document-level and page-level citations
- Clean backend architecture with FastAPI
- Interactive Streamlit UI
